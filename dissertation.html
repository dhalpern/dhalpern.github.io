Tracing Memories Over Time Using fMRI and Behavior

David J. Halpern

For forty years, cognitive neuroscientists have investigated the neural correlates of successful memory formation using neuroimaging. However, what exactly these signals represent and how they evolve with learning over time remain open questions. In this thesis, I leverage a large data set of 57 participants performing second-language learning task while in an MRI scanner to gain more insight into neural signals that accompany learning. It is commonly assumed that at least some signals that correlate with successful encoding reflect moment-to-moment fluctuations in internal states like attention and readiness to encode.

In the first chapter, I test this assumption by asking whether both univariate and multivariate neural signals that have been shown to correlate with successful encoding contain information about whether an item will be remembered beyond what could be predicted based on that item's average memorability in the population. If they did reflect endogenous states of attention and readiness, they would be expected to improve prediction. However, I find that they do not, suggesting that these particular signals, in this task, may be representing features of the items being studied rather than variation in endogenous states.
Chapter 1: Item Learnability and Subsequent Memory Prediction

In order to identify novel signals that might track a participant's learning, the second chapter uses cognitive modeling and a large data set of 150 subjects performing the same task outside the scanner to make precise predictions about the evolution of memory signals over time. Using these techniques, I show that a model-based approach can identify memory-related signals that are not detected by standard approaches. These signals occur in learning and memory related regions such as the caudate nuclei suggesting that this model-based approach can be a more sensitive method for tracking learning over time with fMRI.

Finally, the last chapter explores how combining large behavioral and fMRI data sets can improve inferences in general and the implications that this might have for the design of future cognitive neuroscience studies, particularly in studies of learning and memory where it is difficult to collect many trials in the same subject.
